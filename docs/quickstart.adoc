= Quick Start

Apply the `io.github.jigga.helm` plugin to your Gradle project:

[source,groovy,role="primary",subs="+attributes"]
.Groovy
----
plugins {
    id 'io.github.jigga.helm' version '{project-version}'
}
----

[source,kotlin,role="secondary",subs="+attributes"]
.Kotlin
----
plugins {
    id("io.github.jigga.helm") version "{project-version}"
}
----


Put your Helm chart sources into `src/main/helm`:

----
📂 (project root)
    📂 src
        📂 main
            📂 helm
                📂 templates
                    📄 ...
                📄 Chart.yaml
                📄 values.yaml
----

Use the `helmPackage` task to build your chart.
